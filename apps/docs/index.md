  - title: Typed against your server
    details: TypeScript types are generated from the exact Paper version and plugins your server runs, with Javadoc.
  - title: Server-driven web UIs
    details: Open screens and HUD layers built with HTML/CSS/JS. Views call your server with fetch('/api/...') and WebSockets.
  - title: A platform for plugins
    details: The handshake, views, API routes and resources are a public Java API other plugins build on too.
